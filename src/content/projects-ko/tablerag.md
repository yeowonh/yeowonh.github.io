## 문제 정의

엔터프라이즈 테이블 업무에서는 사용자 질문과 원천 데이터의 언어, 스키마, 표기 방식이 달라
신뢰할 수 있는 답변을 만들기 어렵습니다. 데이터 전환 이후 기존 검색 파이프라인이 정답 행을
놓치거나 충분한 근거 없이 답변을 시도하는 문제가 나타났습니다.

## 해결 전략

- **평가를 재현 가능한 체계로 만들었습니다.** 과제 특화 평가 데이터셋과 검색·답변 정량 지표를
  구축하고, 변경 사항을 자동 비교할 수 있는 평가 주기를 구현했습니다.
- **검색 전략을 결합했습니다.** Hybrid Search 기반 OpenSearch 검색에 Text-to-SQL과 DocumentSQL
  경로를 더해 구조화 질의와 비정형 검색의 장점을 함께 활용했습니다.
- **순위화와 언어 정합성을 개선했습니다.** Cross-Encoder Reranking, 프롬프트 고도화, 한국어
  질문과 영문 테이블 스키마를 연결하는 번역·정규화 단계를 적용했습니다.
- **근거 기반 답변을 설계했습니다.** 질의 분해, 근거 검증, 근거가 부족한 질문에 대한 거절 안내를
  포함하는 Agentic RAG 흐름을 설계해 무근거 답변을 줄이는 방향을 제시했습니다.

## 성과

- **검색 품질 | retrieval correctness 84.21%를 달성해 베이스라인 76.85%보다 7.36%p 높였습니다.**
  검색 결과에 질문에 답할 수 있는 근거가 포함되어 있는지를 측정한 지표입니다.
- **답변 품질 | answer correctness 68.36%를 달성해 베이스라인 59.85%보다 8.51%p 높였습니다.**
  검색 결과가 아니라 최종 답변이 질문에 정확히 답했는지를 측정한 지표입니다.
- **응답 시간 | 주요 비교에서 전체 응답 시간을 43.5초에서 18.2초로 단축했습니다.** OpenSearch와
  SQL 결과를 분리해 Reranking한 비교에서는 답변 품질이 추가로 2.0%p 개선되었습니다.
- **평가 운영 | 데이터셋, 지연 시간 세부 지표, 자동 점수 비교를 포함한 반복 가능한 품질 개선 체계를
  정착시켰습니다.**
- **신뢰성 | 충분한 근거가 없는 질문에도 유창한 답변을 생성하는 대신, 근거 확인과 거절 규칙을
  포함하는 제품 방향을 수립했습니다.**
