## 문제

한국의 이주노동자는 법률, 비자, 일상생활, 구직에 관한 답을 필요로 하지만, 이들을 지원하는
상담센터는 인력 감소를 겪고 있었습니다. 전화를 연결하기도 어렵고, 연결된 뒤에도 법률 문제에
언어 장벽까지 더해졌습니다.

Hello World는 이 문제를 한곳에서 해결하기 위해 시작했습니다. 자주 묻는 질문은 AI 컨택센터가
대응하고, 필요한 경우 상담과 구직용 자기소개서 작성까지 이어지는 통합 지원 경험을 목표로 했습니다.

## 접근 방식

- **법령 원문보다 실제 상담 사례를 우선 검색했습니다.** 법률 문서는 규칙을 설명하지만 당사자가
  다음에 무엇을 해야 하는지까지 알려주지는 않습니다. 이주노동자 관련 상담 사례를 수집하고 정제해
  MongoDB에 적재한 뒤, 실제 상담사가 처리했던 가장 유사한 사례를 바탕으로 답하도록 LangChain
  채팅 에이전트를 구축했습니다. 유창하기만 한 답이 아니라 신뢰할 수 있는 답을 만든 핵심 결정입니다.
- **다국어 자료를 연결했습니다.** 번역된 법률 자료, 분석된 법령과 규정, 상담 이력을 지식베이스로
  구성해 사용자가 자신의 언어로 질문할 수 있게 했습니다.
- **사람에게 필요한 맥락을 요약했습니다.** 모든 사례가 채팅으로 끝나지는 않습니다. 상담이 사람에게
  넘어갈 때 같은 내용을 처음부터 다시 묻지 않도록 세션 로그를 요약해 상담사에게 전달했습니다.
- **서버리스 백엔드로 운영 부담을 낮췄습니다.** Azure Functions로 스트리밍 채팅, 대화 요약,
  자기소개서 생성을 제공하고 유휴 비용을 줄였습니다. 병합 시 GitHub Actions가 자동 배포합니다.

### 주요 API

| 엔드포인트 | 용도 |
| --- | --- |
| `POST /api/chat/ask` | 스트리밍 채팅 응답 |
| `POST /api/summary` | 상담사용 대화 요약 |
| `POST /api/cv_generation` | 대화를 바탕으로 자기소개서 초안 생성 |
| `GET /api/chat/rooms` | 대화방 목록 조회 |
