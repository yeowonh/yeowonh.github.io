## 문제

두 사람의 대화 요약은 비교적 잘 풀린 문제지만, 여러 사람이 참여하는 대화는 다릅니다. 여러 주제가
동시에 진행되고 잠시 사라졌다가 열 차례 뒤 다시 등장합니다. 전체 대화를 하나의 요약으로 압축하면
독자가 실제로 필요로 하는 주제별 맥락을 잃게 됩니다.

과제는 대화 안의 여러 주제를 식별하고 각각을 요약하는 것이었습니다.

## 접근 방식

- **EDA와 오류 분석으로 방향을 정했습니다.** 기준 모델의 실패를 바탕으로 전처리 전략과 프롬프트를
  설계해, 근거 없는 리더보드 튜닝을 피했습니다.
- **주제 식별과 요약을 분리했습니다.** 전체 대화를 하나의 일반적인 요약으로 합치지 않고 서로 다른
  대화 흐름을 보존할 수 있도록 파이프라인을 구성했습니다.
- **가용한 학습 및 추론 예산 안에서 동작하도록 모델을 양자화하고 튜닝했습니다.**

## 성과

- **대회 성적 | 국립국어원 일상 대화 요약 경진대회 5위 및 본선 진출.**
- **모델 효율 | 대회 학습·추론 예산 안에서 양자화 모델 완성.** 제한된 자원에 맞춰 양자화와
  하이퍼파라미터 튜닝을 적용했습니다.
- **평가 기반 개발 | 기준 모델의 실패 패턴을 전처리와 프롬프트 의사결정으로 전환.** 리더보드
  점수만 좇지 않고 오류 분석을 중심으로 반복 개선했습니다.
